# 🎓 Student Grade Calculator

A desktop-based Student Grade Calculator built using Python and Tkinter. The application calculates students’ total marks, percentage, grade, and pass/fail status based on marks entered for five subjects, with input validation and an easy-to-use graphical interface.

## ✨ Features

- **Student Details:** Enter the student's name and roll number.
- **Marks Entry:** Input marks for five subjects.
- **Automatic Calculation:** Calculates total marks and percentage instantly.
- **Grade Evaluation:** Assigns grades based on the calculated percentage.
- **Pass/Fail Status:** Displays the result with visual indicators.
- **Progress Bar:** Shows the percentage visually.
- **Input Validation:** Handles missing details, invalid numbers, and marks outside the permitted range.
- **Quick Actions:** Calculate, redo, and exit buttons.
- **Keyboard Shortcut:** Press Enter to calculate the result.

## 🛠️ Technologies Used

- **Python** — Application logic and calculations
- **Tkinter** — Graphical user interface
- **ttk** — Progress bar styling
- **Messagebox** — Input validation and error notifications

## 🏆 Grading Criteria

| Percentage | Grade |
|---|---|
| 90–100% | A+ |
| 80–89.99% | A |
| 70–79.99% | B |
| 60–69.99% | C |
| 50–59.99% | D |
| Below 50% | F |

A student receives **PASS** for grades A+ through D and **FAIL** for grade F.
